# 分散资产配置

A股主动管理的阶段性优势很大程度上来自行业配置。2026年一项基于2015—2022年中国权益基金的研究发现，行业集中可以提高基金表现，主要机制是经理的专业化行业配置；但投资者申赎反而会侵蚀收益。这说明“研究产业周期”有价值，但“在业绩爆发后追明星基金”并不能赚钱。

对一个愿意投入较多时间做产业研究、但又不希望投资失败影响长期资产积累的人，我的投资结构是：

| 层级               | 功能                                  | 参考风险预算 |
| ------------------ | ------------------------------------- | -----------: |
| 第一层：流动性     | 应急、等待机会、降低被迫交易风险      |      10%—20% |
| 第二层：质量与分红 | 现金流、垄断壁垒、股东回报            |      25%—40% |
| 第三层：市场Beta   | 获得A股整体长期收益，避免选股永久失误 |      25%—40% |
| 第四层：产业周期   | 技术扩散、景气突破、非对称收益        |      10%—25% |

---

## 一、流动性：基本生活

**逆回购只是停车场，不是组合主要收益来源。**这一层的目标不是跑赢通胀或获得高收益，而是：

- 不被迫卖出股票；
- 在市场大幅下跌时有资金；
- 满足近期生活和确定性支出；
- 降低整个组合的净值波动。

国债逆回购适合处理证券账户中的短期闲置资金，但其收益率由资金市场决定，不是固定高收益产品。交易所回购按照**实际占款天数**计息，利息按成交金额、成交利率、实际占款天数和365天计算；节假日前收益天数较多，但报价也会随市场调整。

## 二、攒股收息：跑赢通胀

> 明星公司＋高股息垄断央企＝长期底仓，并争取跑赢指数。
> 但“高股息”并不天然等于“跑赢指数”。

从高股息央企和优质公司中寻找：

- 稳定自由现金流；
- 合理资本开支；
- 低负债或可控负债；
- 分红能够由利润和现金流覆盖；
- 行业格局稳定；
- 估值不过度透支。

但政策支持不能消除以下风险：

- 银行的息差与不良资产风险；
- 煤炭、石油的商品周期风险；
- 电信运营商资本开支上升；
- 电力企业水文、燃料价格和电价机制风险；
- 分红率提高但利润下降；
- 股价上涨后股息率优势消失。

## 三、市场Beta：跑赢指数

主动基金在某些A股市场环境下确实能够跑赢，但随着观察期限拉长，跑赢的难度总体会上升。单一年份行业分化可以让大量主动基金胜出，但不能确保长期持续，需要鉴别行业主题风格和市场风险偏好。

| 行情                            | 本质                         | 首要触发因素                     | 后期推动因素                        | 主要结束机制                                     |
| ------------------------------- | ---------------------------- | -------------------------------- | ----------------------------------- | ------------------------------------------------ |
| 2019—2021年初消费、医药         | 优质资产稀缺＋机构化定价     | 外资进入、盈利稳定、低利率       | 公募基金抱团、核心资产营销          | 估值过高、利率上升、资金踩踏、医药监管           |
| 2020—2021年新能源               | 技术渗透率突破＋国家产业政策 | 电动车和光伏经济性改善、双碳政策 | 赛道基金、产能投资、渗透率叙事      | 产能过剩、价格战、利润率下降、估值压缩           |
| 2021—2024年煤炭、油气、高股息   | 供给稀缺＋现金流重估         | 能源短缺、俄乌冲突、资本开支不足 | 低利率、中特估、分红政策、ETF资金   | 商品价格回落或经济增长风格重新占优               |
| 2024—2026年半导体、AI硬件、材料 | 全球AI资本开支＋国产替代     | 大模型、算力需求、海外客户订单   | 大基金三期、AI+、DeepSeek、公募抱团 | 尚未完全结束；当前进入资本开支回报与业绩验证阶段 |

可覆盖：

- 大盘；
- 中盘；
- 市场整体；
- 必要时加入一定成长权重。

## 四、康波与产业周期：人生发财

> **技术扩散与产业资本周期研究**：这是整个体系中最有可能创造显著超额收益的部分，也是最容易亏损的部分。

很多技术最终改变了世界，但早期投资者没有赚到钱，因为技术突破与股票上涨之间隔着很长的传导链：

> 技术突破
> → 产品形成
> → 客户愿意付费
> → 规模化生产
> → 产业利润池形成
> → 上市公司获得利润
> → 当前估值仍未充分计价

| 阶段   | 证据                                 | 仓位原则 |
| ------ | ------------------------------------ | -------- |
| 观察仓 | 技术突破、政策支持，但订单不明确     | 极小仓位 |
| 验证仓 | 客户订单、收入增长、产能利用率改善   | 逐步增加 |
| 主升仓 | 盈利上调、行业扩散、瓶颈仍存在       | 核心持有 |
| 拥挤期 | ETF爆发、研报同质化、估值快速提升    | 停止加仓 |
| 退出期 | 产能增速超过需求、价格下降、盈利见顶 | 系统减仓 |

### 产业研究

观察一个产业的**技术—需求—利润—产能—资本市场周期**：

1. **谁付钱？**
2. **收入什么时候形成？**
3. **产业利润落在哪个环节？**
4. **瓶颈能维持多久？**
5. **竞争者扩产需要多长时间？**
6. **这家公司能获得多少现金流？**
7. **当前市值已经计入多少成功概率？**

### 产业链组合

更稳健的做法是产业链组合，这样可以降低单一公司技术失败、客户流失或财务造假的风险。

- 核心龙头；
- 关键瓶颈；
- 上游材料；
- 设备或基础设施；
- 少量高风险技术公司。
