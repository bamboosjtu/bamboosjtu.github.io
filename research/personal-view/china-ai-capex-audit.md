# 中国AI基建叙事审计

过去几年，美股科技股这一轮牛市背后有一条很硬的主线：AI从一个软件故事变成了一场资本开支竞赛。

Amazon、Microsoft、Google、Meta不断建设数据中心、采购GPU和网络设备，投资规模已经大到开始改变这些公司的现金流结构。Amazon预计2026年资本开支约2000亿美元；Alphabet给出的2026年指引已经达到1800亿—1900亿美元；Meta是1300亿—1450亿美元；Microsoft则预计2026自然年资本开支约1900亿美元。四家公司加起来，一年就是**7000亿—7250亿美元**。Amazon甚至明确告诉投资者，愿意承受短期自由现金流压力换取未来AI收益；Google开始同时使用经营现金流、债务和股权融资扩张基础设施；Meta上半年也发行了约249亿美元债券。

这才是美国AI牛市背后的底色：**不是Token增长了多少，不是模型排行榜又赢了一次，而是世界上现金流最强的几家公司，真的在一年花掉几千亿美元买计算机。**

中国资本市场很自然地复制了这套叙事，而且还多叠了一层国产替代。阿里、腾讯、字节增加AI投入，三大运营商建设智算中心，“东数西算”提供数据中心和能源底座，美国又限制高端GPU供应，于是华为昇腾、寒武纪、沐曦、摩尔线程理论上同时拥有“AI需求爆发”和“国产替代”两重增长空间。

这个故事实在太完美了。完美到我反而想把账算一遍。

AI基建不是玄学，它最终一定会留下三种痕迹：**模型调用要消耗电，基础设施扩张要花CAPEX，国产替代最终要变成国产GPU的卡数和收入**。如果中国真的正在复制美国的AI基础设施超级周期，这三笔账至少应该在数量级上大致互相印证。

**现在看，三笔账并不太对得上。**

## 一、Token爆炸，但在电表上看不出来

官方公布的Token曲线非常惊人。2024年初，中国日均Token调用量大约只有1000亿；2025年底已经达到100万亿；2026年3月进一步超过140万亿。两年左右增长超过1000倍。国家数据局甚至把Token称为连接技术供给和商业需求的“结算单位”。

如果只看这条曲线，很容易认为中国AI已经进入大规模普及阶段。

但我更愿意看电表。2026年上半年，全国互联网数据服务业用电量494亿千瓦时，同比增长44%。这个增速当然很快，但绝对量只占同期全国50999亿千瓦时用电量的**0.97%**。互联网数据服务业和充换电服务业加在一起，也只拉高全国用电量0.9个百分点，而且充换电服务业本身用了810亿千瓦时，比互联网数据服务还多。

这里当然不能简单拿“Token增长1000倍”和“电量增长44%”直接做弹性比较。时间区间不同，单位Token能耗也在快速下降；MoE、量化、KV Cache、批处理都会降低推理成本，Agent又会让一次用户行为在后台产生几十甚至上百次模型调用。

**但数量级差得实在太远。**更重要的是，494亿千瓦时统计的是**整个互联网数据服务业**，里面还有传统云计算、存储、CDN、视频和其他互联网负荷，并不是纯AI用电。所以真正的大模型训练和推理用电只会低于这个数字。

因此我现在不会得出“Token数据一定有水分”这么武断的结论，但会得出一个更直接的判断：

**至少从电力这张物理账来看，中国AI的真实渗透远没有Token曲线表现得那么猛烈。**

数字世界已经呈现千倍增长，电力世界看到的仍然只是一个占全国用电不到1%的行业以40%左右的速度增长。这意味着中国AI当然有人用，而且用量正在增长，但离“AI已经成为宏观经济级别的新负荷”还有明显距离。

这是第一处值得警惕的地方，**Token已经像移动互联网一样繁荣了，但电表暂时还不像。**

## 二、CAPEX暴增，但不及美国六分之一

第二笔账不能只盯着三大运营商，而应该把中国主要算力买家放在一起。

我索性采用一个对“中国AI基建”尽可能有利的算法：三大运营商连传统通信CAPEX都全部算进去，阿里和腾讯按最新资本开支速度估算，字节采用媒体预测，再把润泽智算、弘信电子这样的第三方算力基础设施投资也加进来。

先看运营商。中国移动2026年计划CAPEX 1366亿元，中国电信730亿元，中国联通500亿元，合计约**2596亿元**。这里面显然不全是AI：中国移动仍然要建设移动通信网络，中国电信也只有255亿元明确属于算力基础设施，中国联通则计划将35%以上CAPEX用于算力。也就是说，我把2596亿元全部算作AI相关，实际上已经明显往大了算。

互联网公司的数字更值得看。阿里截至2026年3月的财年CAPEX已经达到1261亿元，最新一个季度又直接砸了677亿元，同比增长75%；按最近12个月滚动计算，CAPEX大约已经达到1550亿元，如果把最新季度简单年化，甚至超过2700亿元。

腾讯也开始明显提速。2025全年CAPEX是792亿元；2026年一季度319亿元，二季度直接增加到528亿元，上半年已经达到847亿元。更有意思的是，腾讯2026年二季度自由现金流首次转成**负138亿元**，原因之一就是AI基础设施采购和预付款。这说明腾讯已经开始出现一点美国科技巨头那种“用现金流换算力”的味道。

字节没有上市，数字只能采用外部估计。《金融时报》报道其2026年计划AI相关资本开支约1600亿元。

第三方AIDC里，润泽智算2025年购建固定资产等支付现金121.5亿元；弘信电子只有约5.5亿元，其中约4.2亿元用于高性能服务器设备。

把这些东西粗暴地堆在一起，会得到一个很有意思的区间。

| 中国主要算力投资主体 | 用于估算的年度规模  |
| -------------------- | ------------------- |
| 三大运营商           | 2596亿元            |
| 阿里                 | 1550—2700亿元       |
| 腾讯                 | 1170—1690亿元       |
| 字节                 | 约1600亿元          |
| 润泽科技             | 约120亿元以上       |
| **合计**             | **约7000—9000亿元** |

这个数字不是一个精确的“中国AI CAPEX”。恰恰相反，它是我故意制造的一个**偏大的上限估计**。运营商传统通信建设被我算进来了；润泽这样的AIDC公司很可能建设的正是阿里、字节或者其他客户使用的数据中心，存在重复统计；阿里最新一个季度又可能存在采购节奏波动。**也就是说，真实数字大概率比7000—9000亿元更低，而不是更高。**

然后再看美国。Amazon约2000亿美元，Microsoft约1900亿美元，Alphabet约1800亿—1900亿美元，Meta约1300亿—1450亿美元，合计**7000亿—7250亿美元**。用一个粗略的7元人民币兑1美元来做数量级换算，就是接近**5万亿元人民币**。

于是出现了一个很尴尬的结果：

> 我已经把中国的数字尽量往大了算，甚至把运营商非AI投资和可能重复计算的IDC投资都塞进去了，中国主要玩家的AI相关CAPEX仍然只有美国四家公司的大约 **14%—18%**，也就是六分之一左右。

这和资本市场给人的感受完全不一样。**A股现在讨论的是“全球AI算力浪潮+国产替代”，但真正落到资本开支规模，中国和美国暂时根本不是一个量级。**

当然，7000—9000亿元人民币本身已经是一个巨大的产业。但如果讨论的是“中国正在复制美国AI CAPEX超级周期”，那就必须承认：**目前还差了大约五六倍。**

而且，中国这7000—9000亿元里相当一部分还是运营商的存量资本预算迁移。美国四巨头则是真正把资产负债表往前推，Microsoft一个自然年的CAPEX就接近1900亿美元；Google的2026年CAPEX预计比2025年接近翻倍。

所以第二笔账给我的感觉不是“中国没有AI CAPEX”，而是：**中国AI投资当然很大，但和美国正在发生的那场资本开支海啸相比，目前仍然只是另一种规模的事情。**

## 三、GPU国产替代，但收入只是百亿级

最后看国产GPU。2025年寒武纪收入64.97亿元，沐曦16.44亿元，摩尔线程15.06亿元。三家加起来只有**96.5亿元**。其中沐曦2025年训推一体GPU销量3.36万片，推理GPU4946片，至少证明芯片不是PPT，确实在出货；但同时也告诉我们，目前还是数万片的规模。

最大的华为昇腾没有单独披露收入，这一直是国产GPU这笔账最大的黑箱。但最近流出的梁文锋投资者交流，终于给了一个可以做数量级估算的锚点。

先说明：这不是DeepSeek官方财务披露，所以不能当成审计数据。但现有流出的文字稿高度一致，梁文锋披露华为给DeepSeek的大约是**1.6万张950的产能**，而互联网大厂可能拿到“十几万张”级别；更关键的是，他直接说1.6万张华为950只相当于大约4000张NVIDIA B系列卡。

梁文锋把两家的硬件差距总结得很形象：**“四倍加两年。”**

也就是四张华为950大约顶一张GB300，而产品节奏落后大约两年。对于价格，他说得更有意思：华为方案贵50%、贵100%，甚至贵200%都可以接受；以贵100%为例，他认为在当前供应条件下也可以算“平替”。

这句话如果翻译成商业语言，其实很残酷：

> 国产算力当前最大的优势不是“便宜”，甚至不是“性能相同”，而是**可以买到**。

我自己调研到的上一代昇腾910服务器价格大约是180万元一台，如果按8卡服务器粗算，每张卡对应约22.5万元整机价值。这个数字不是华为GPU售价，里面还有CPU、内存、电源、整机和渠道利润，所以用它估华为收入实际上是**往高了估**。

仅凭梁文锋一句“互联网大厂十几万张”当然推不出华为全年总销量，因此我做三个情景，而不是假装知道精确数字。

| 华为高端AI卡假设出货 | 按22.5万元/卡估算整机价值 | 按“四卡顶一卡”折算GB300等效 |
| -------------------- | ------------------------- | --------------------------- |
| 15万张               | 338亿元                   | 3.75万张                    |
| 25万张               | 563亿元                   | 6.25万张                    |
| 40万张               | 900亿元                   | 10万张                      |

再把寒武纪、沐曦和摩尔线程的96亿元收入全部加进去，中国国产高端AI算力产业在这三个情景下大约就是**430亿、660亿、1000亿元**的量级。注意，我已经做了两个对国产GPU极其有利的处理：华为按整台服务器价值而不是芯片收入计算，而且40万张本身已经是一个相当激进的出货假设。

然后看看英伟达。英伟达2026财年仅Data Center收入就是**1937亿美元**，其中计算业务1624亿美元。粗略折成人民币，就是一万多亿元。

所以哪怕采用我最激进的40万张华为卡情景，再把寒武纪、沐曦、摩尔线程全部加上，国产GPU产业规模也就是英伟达数据中心业务的**个位数百分比**。这才是我觉得目前国产算力叙事最值得警惕的地方。资本市场谈的是“国产GPU全面替代英伟达”，现实里的产业体量却可能还是几百亿元对一万多亿元。

而且卡数本身还会制造第二重错觉。

假如华为真的出货40万张，新闻标题会是“四十万张国产AI芯片”。听起来已经非常接近美国大型集群了。但按照梁文锋自己的工程经验，四除一以后只有10万张GB300级等效算力。更麻烦的是，如果同样任务的系统价格还要贵一倍，那么**中国花两倍CAPEX，可能只是买到了四分之一的单卡性能。**

这会出现一个非常反直觉的现象：**国产GPU越贵、为了追平性能堆的卡越多，中国AI CAPEX的数字反而越漂亮。**

一个500亿元的国产算力项目，不一定代表它比一个300亿元的NVIDIA项目提供更多有效算力，它也可能只是因为完成同样任务需要更多芯片、更多服务器、更多交换机和更多电。

所以拿“中国投资了多少亿”直接证明“中国AI算力很强”，本身就是一个很危险的循环论证。

## 结论：现在更像是一个被透支的国产算力故事

把三笔账摆在一起，我现在对“中国AI基建”的判断比市场主流叙事悲观得多。

第一笔账，Token两年增长千倍，但互联网数据服务用电仍只占全国不到1%，增速也只是40%左右。不能说Token是假的，但**至少从最硬的物理指标——电力——看不出同样强度的AI渗透。**

第二笔账，中国主要玩家的资本开支当然不小。我甚至故意把运营商非AI投资和可能重复统计的数据中心CAPEX都算进去，得到的仍然只是每年7000亿—9000亿元人民币。而美国四家科技巨头今年准备花7000多亿美元。**中国大约只有美国的六分之一。**

第三笔账更刺眼。寒武纪、沐曦、摩尔线程加起来不到100亿元收入；华为没有财务披露，按梁文锋透露的卡数和我调研到的服务器价格往大了估，整个国产高端GPU产业大概也只是几百亿到一千亿元级别。与此同时，英伟达一个公司的数据中心收入已经是一万多亿元人民币。

更何况梁文锋本人给出的技术判断并不含糊：**四张顶一张，落后两年，系统贵一倍仍然可以接受。**我反而觉得这句话把目前的国产算力说得最清楚。它不是骗局，也不是“已经追平”。

它目前首先是一种**战略替代品**：因为真正想要的NVIDIA买不到，所以国产卡即使性能差、成本高，也有巨大的使用价值。这个逻辑足以支撑一个重要产业，但它和“国产GPU已经拥有英伟达级别的商业竞争力”完全是两件事情。

**更重要的是，A股现在给出的估值明显不是按照“战略备胎”定价，而是在按照它未来变成全球主流AI基础设施之后定价。**

我现在真正怀疑的不是中国能不能最终做成国产GPU。国家级投入、市场规模和工程师数量摆在那里，长期做出来并不奇怪。

我怀疑的是另一件事：**资本市场是不是把十年后的胜利，提前当成了今天的收入。**

目前这三笔账给我的答案，至少还没有乐观到那个程度。
