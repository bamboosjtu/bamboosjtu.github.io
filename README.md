## 目录结构

```text
knowledge/
├─ llm/                    # 模型基础、提示词工程、LLM Agent、RAG
```

新增课程时，不创建课程目录。先判断它研究的对象，再把有效内容归入相应领域；课程名称只记录在 `references/`。
